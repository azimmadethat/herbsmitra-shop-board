# Shop Board, WooCommerce version

The original kit in the zip reads Shopify only. This folder is the same board
with the data layer swapped to the WooCommerce REST API, so it shows real
Herbs Mitra orders from herbsmitra.com today, before the Shopify move. The
five designs, the popup, the chime, the confetti, the TV app and the optional
Meta numbers and voice assistant are all unchanged.

One link runs on every device: phone browser, laptop Chrome (F11 for full
screen), TV web browser, laptop over HDMI, or the Android TV app. The popup
for each new order reads: From [first name], [items], [city], and the total
price. Only the first name and city reach the screen. No phone number, email
or street address is included.

## New Features & UI/UX Improvements

- **Official Transparent HerbsMitra Logo**: Integrated the official HerbsMitra emblem and wordmark with a clean transparent background across all board themes and the Operations command center.
- **Iconic Cha-Ching Sound Synthesizer**: Replaced the basic beeps with an authentic, rich Web Audio cash register "Cha-Ching!" notification with metallic drawer slide, coin rattles, and resonant brass bell sustain.
- **Best Days as per Orders & Calendar View**:
  - Top navigation button `🏆 Best Days Calendar` on both the TV board HUD and Operations Dashboard.
  - Interactive calendar month view displaying order counts, revenues, and medal badges (🥇, 🥈, 🥉) on peak days.
  - Quick leaderboard of top 3 all-time highest order days with instant click-to-load.
- **Removed Voice Feature**: Removed all microphone buttons, speech recognition, and audio synthesis clutter from the TV board and theme footers, giving full screen space to the live order chips.
- **Disabled Forced Night Dimming Mode**: Removed the automatic 1am-7am `filter: brightness(.45)` sleep mode so displays remain vivid and clear 24/7.

## What changed, file by file

- `functions/_woo.js` (new): reads WooCommerce orders and builds the exact
  snapshot the designs expect. Replaces the kit's `functions/_board.js`,
  which was deleted from this folder. Keep the original zip for the Shopify
  version.
- `functions/api/state.js`: now imports the snapshot from `_woo.js`.
- `functions/api/health.js`: checks the WooCommerce connection instead of
  Shopify.
- `functions/api/ask.js`: one import changed, snapshot now comes from
  `_woo.js`.
- `public/board.js`: two lines changed. The new-order popup and the recent
  order chips now show the customer's first name.
- Everything else (`functions/_lib.js`, `functions/_ai.js`,
  `functions/index.js`, the five theme files, `tv.apk`, scripts) is copied
  from the kit unchanged. The Meta and voice code is untouched.

## Setup, one step at a time

You do the clicking. Your AI runs the commands. About 30 to 45 minutes.

### 0. Node.js (2 min)

Node 18 or newer, then inside `board-woo/` run `npm install`. This installs
Cloudflare's tool, `wrangler`.

### 1. Cloudflare account (5 min)

Run `npx wrangler login` from `board-woo/` and allow it in the browser.
Confirm with `npx wrangler whoami`. Pick a project name like
`shopboard-herbsmitra` (lowercase, at most 28 characters). Set
`name = "shopboard-herbsmitra"` in `wrangler.toml`, then create it:
`npx wrangler pages project create shopboard-herbsmitra --production-branch main`.
Create storage: `npx wrangler kv namespace create BOARD_KV`, copy the id
into `wrangler.toml` by uncommenting the `[[kv_namespaces]]` block. Do not
skip this, without it the board asks WooCommerce much more often.

### 2. WooCommerce read-only key (10 min)

In the WordPress admin, go to WooCommerce, Settings, Advanced, REST API,
Add key. Description: `Shop Board read only`. User: the shop manager or
admin account. Permissions: **Read**. Generate it. The secret is shown once
only. Hand the key and secret to your AI through the Secure Vault flow.
Never paste them in chat, email or any other file.

Add to `board-woo/.secrets.env` (copy `.secrets.env.example` first):

```
WC_URL=https://herbsmitra.com
WC_KEY=ck_...
WC_SECRET=cs_...
BOARD_KEY=<12 random lowercase letters and digits, generated by your AI>
STORE_NAME=Herbs Mitra
STORE_TZ=Asia/Kolkata
```

The board link needs `BOARD_KEY` so only people with the link see the sales:
`https://<project>.pages.dev/?k=<BOARD_KEY>`. Anyone with the link can see
the numbers, so keep it private.

### 3. Meta ads (optional)

Same as the kit: a read-only System User token with `ads_read` only, from
Business Settings. This is the same token the optimiser needs. Add
`META_TOKEN`, `META_AD_ACCOUNT` and `BREAK_EVEN_ROAS` to `.secrets.env`.

### 4. Voice assistant (optional)

Same as the kit. Without a key the mic still answers simple questions from
the numbers. With an Anthropic or OpenAI key it also writes the morning
greeting.

### 5. Pick a design and go live (5 min)

Add `BOARD_DESIGN=<apple, meta, herbsmitra, classic, studio, garden, swiss or night>` to
`.secrets.env` if you want a fixed design. You can flip designs any time
with the on-screen HUD switcher, or left and right arrows on the remote, so the choice is not final.
Then, from `board-woo/`:

```
node scripts/push-secrets.mjs <project>
npx wrangler pages deploy public --project-name <project> --branch main --commit-dirty=true
```

`push-secrets.mjs` uploads every line of `.secrets.env` to Cloudflare and
then deletes the local file. The keys then live only in Cloudflare.

### 6. Check it works (2 min)

```
node scripts/check.mjs "<board link with ?k=...>"
```

Every line should be a tick, or a dash for parts you skipped. Open the link
in Chrome on a computer. Press **T** to play a pretend order with sound and
animation. Click once first if the browser asks to allow sound.

### 7. Put it on the TV (5 to 10 min)

Google TV / Android TV / Fire TV: install the Downloader app, allow unknown
sources, open Downloader, type `<project>.pages.dev/tv.apk`, install, open,
and type the full board link. Samsung, LG or another smart TV: open the TV
web browser, type the board link, bookmark it. Any TV: laptop over HDMI,
Chrome, F11. Turn off the TV sleep timer in Settings so the board stays on.
Sound plays after one press of OK on the board. The voice assistant needs
the TV app or Chrome on a computer, TV browsers cannot use the mic.

## Honest limits

- History covers the last 14 days. Yesterday comparison, the daily
  projection and the best-day line all work. The "best same weekday in 8
  weeks" insight needs 56 days and will not fire.
- Cancelled, refunded and failed orders are left out of today's sales. An
  order cancelled later disappears from the board the next refresh. The
  board can differ a little from WooCommerce reports, which handle refunds
  differently. That is expected.
- "New customer" is checked only for the 6 most recent orders, to keep the
  board fast. Older orders report it as false.
- The board refreshes every 20 seconds. WooCommerce numbers update as soon
  as an order is placed. Meta numbers refresh every 15 minutes and lag a
  little, as in the kit.
- If the site uses a security plugin that strips the Authorization header,
  the API returns 401. The fix is in that plugin's settings, never put the
  key in the URL as a workaround.

## Switching to Shopify later

When Shikha's Shopify store is live, the original kit works as written.
Deploy the original `board/` folder with the Shopify app from the kit's
guide, using a new project name or by swapping the secrets. This WooCommerce
folder stays as the fallback until the first clean day on Shopify. Do not
delete it until the switch is proven.

## Troubleshooting

| What you see | What to do |
|---|---|
| `WooCommerce HTTP 401` | Key or secret wrong, site not on HTTPS, or a security plugin stripping the Authorization header. Regenerate the key with Read permission and try again. |
| `WooCommerce HTTP 404` | WC_URL is wrong, or pretty permalinks are off. WC_URL must be the store address, e.g. `https://herbsmitra.com`, with no trailing path. |
| Board shows "This board link is missing its key" | The link must end in `?k=<BOARD_KEY>`. |
| No cities or first names | The Read key cannot see order billing details. Check the key's user has shop manager or admin rights, then regenerate it. |
| Changes do not show on the TV | Restart the TV app after a redeploy, or wait a minute. |
| Project name taken | Add a suffix and update `name` in `wrangler.toml`. |

## Ops page (added later)

`public/ops.html` is the all-orders page: KPIs, the status pipeline, top
cities, top products, every order today with search and a status filter,
low stock, and the ad numbers. It reads `/api/state?full=1`.

New snapshot fields in `functions/_woo.js`: `statuses` (counts and amounts
for pending, processing, on-hold, completed, cancelled, refunded, failed),
`payment` (COD vs prepaid), `product_sales` (units and revenue per product),
`customers` (new, returning, guest), `low_stock` (products at or below their
low-stock amount, or out of stock, null when products cannot be read), and
`orders_today` (every order today with status, first name and city only, sent
only when `/api/state` is called with `?full=1`). `publicOrder` also carries
`status` and `guest` now. The voice answers in `functions/api/ask.js` cover
the COD split and the pipeline too.
